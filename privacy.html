隐私说明

最后更新：2026-10-14。本文说明 VideoDoctor 如何处理你的媒体与购买信息。

1. 媒体处理

VideoDoctor 在你的 Mac 本地完成探测、诊断与修复。修复过程不要求将视频上传到我们的服务器。源文件以只读方式访问，输出写入你选择的目录。

2. 我们不收集的内容

  • 不会为了修复而收集你的视频内容本身
  • 不会要求账号登录才能使用本地修复能力

3. 购买与权益

若你购买 Pro，交易与收据校验通过 Apple 的 App Store / StoreKit 完成。我们据此解锁本机权益，不另建独立账号体系。

4. 本地存储

应用可能在本机保存任务队列、诊断摘要、输出路径偏好与权益状态，以便你重新打开应用后继续使用。这些数据留在你的设备上。

5. 支持沟通

当你通过邮件或 GitHub Issues 联系我们时，你会主动提供的信息（如系统版本、问题描述）仅用于排查与回复。
